## W2 已确认的决定

| 事项 | 结论 |
|------|------|
| 邮箱 | Better Auth 要求 email 必填 → 按用户名自动生成占位邮箱 `<小写用户名>@users.sl-ai-admin.local`，不校验、用户不可见，邮箱登录接口禁用 |
| 用户名大小写 | 不区分（插件默认），显示保留原始写法 |
| 界面语言 | 登录相关界面统一中文 |
| 测试工具 | 新增开发依赖 Vitest（单元）+ Playwright（Web E2E）；移动端只做类型 / 打包检查 + 用户模拟器手动验收 |
| 数据库 | Homebrew 安装 PostgreSQL 17 并以服务方式运行于 localhost:5432；用 `pnpm db:migrate` 生成迁移 |
| 代码规范闸门 | 全量 `pnpm check` 有 451 个历史遗留错误，闸门改为只检查本次改动的文件：`pnpm exec ultracite check <files>` |
