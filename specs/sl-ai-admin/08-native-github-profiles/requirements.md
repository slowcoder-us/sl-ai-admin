# GitHub 用户管理（移动端） - 需求

> 来源：`docs/首页需求.md` · 1 背景与目标（覆盖端：移动端）、2.1–2.6、3 页面、4 交互要求
> 依赖：03-native-username-auth、04-github-profile-search、05-github-profile-save、06-github-profile-edit-delete

## 背景

移动端需要提供和 Web 相同的 GitHub 用户管理能力。两端共用同一套接口和同一份数据，在任一端的操作，另一端刷新后都能看到。

## 用户故事

- 作为登录用户，我希望在 App 上搜索 GitHub 用户并保存，以便不打开电脑也能管理。
- 作为登录用户，我希望在 App 上修改和删除已保存的记录，以便两端数据保持一致。

## 需求条目

| 编号 | 需求 | 优先级 |
|------|------|--------|
| R1 | 抽屉菜单提供「GitHub 用户管理」，页面只有登录后可达 | P0 |
| R2 | 校验用户名，查询并显示资料，查询失败时按原因提示 | P0 |
| R3 | 点击用户名用系统浏览器打开 GitHub 主页 | P1 |
| R4 | 把搜索结果保存到数据库，重复时提示 | P0 |
| R5 | 显示当前账号保存的全部用户，按保存时间倒序，无记录时显示空状态 | P0 |
| R6 | 修改姓名、简介、所在地，可以取消和清空 | P0 |
| R7 | 删除需要二次确认 | P0 |
| R8 | 操作过程显示加载状态，防止重复提交，同时只操作一条记录 | P1 |

### R1 入口和登录保护

抽屉菜单增加「GitHub 用户管理」，打开后上方是搜索，下方是已保存列表。未登录时该页面不可达，深链接也不例外。

### R2 搜索

规则和提示语与 Web 完全一致，来自共享规则：用户名不合法时显示「请输入有效的 GitHub 用户名」且不发请求；查询失败显示接口返回的提示。显示头像、用户名、姓名、简介、所在地，资料中没有的项不显示。

### R3 打开主页

点击用户名，用系统浏览器打开 `https://github.com/<用户名>`。

### R4 保存

搜索结果旁有「保存用户」按钮。成功后清空搜索结果并刷新列表；重复时提示「该用户已保存」。

### R5 已保存列表

内容与搜索结果相同，按保存时间倒序。列表只含当前账号的记录。没有记录时显示「还没有保存的用户。」

### R6 修改

点「编辑」后就地修改姓名（最多 255 字）、简介（最多 500 字）、所在地（最多 255 字）。三个字段都可以清空，用户名和头像不可修改。点「取消」不保存。

### R7 删除

点「删除」后需要再点「确认删除」才真正删除，点「取消」则保留。记录已不存在时提示「找不到该记录」。

### R8 交互状态

搜索、保存、修改、删除进行中相关按钮禁用；搜索和首次加载列表时显示加载状态。正在编辑或确认删除某条记录时，其他记录的「编辑」「删除」按钮禁用。错误显示在发生错误的区域内。服务器不可达时显示可读的中文提示。

## 非功能需求

- Android 模拟器上键盘弹出时输入框不被遮挡。
- iOS 未验证：本机只有 iOS 17.4 运行时和 Xcode 15.3，可能不支持 Expo SDK 58，iOS 只做 `expo export` 打包检查，已记入遗留问题。
- 支持深色模式（沿用 HeroUI Native 主题）。

## 验收标准

- [ ] AC1（R1）：登录后打开抽屉菜单，有「GitHub 用户管理」，点击进入页面。
- [ ] AC2（R1）：未登录时通过深链接打开该页面，显示登录页。
- [ ] AC3（R2）：输入 `-abc` 并搜索，显示「请输入有效的 GitHub 用户名」，server 日志没有 `lookup` 请求。
- [ ] AC4（R2）：搜索 `octocat`，显示头像、`@octocat`、姓名。
- [ ] AC5（R2）：搜索不存在的用户，显示「找不到该 GitHub 用户」。
- [ ] AC6（R3）：点击用户名，系统浏览器打开对应的 GitHub 主页。
- [ ] AC7（R4）：点「保存用户」，搜索结果清空，列表最前面出现该用户；在 Web 上刷新也能看到。
- [ ] AC8（R4）：再次保存同一用户，提示「该用户已保存」。
- [ ] AC9（R5）：没有记录的账号显示「还没有保存的用户。」，其他账号的记录不出现。
- [ ] AC10（R6）：修改三个字段并保存，列表更新，在 Web 上刷新也一致；点「取消」不保存；清空后对应项不显示。
- [ ] AC11（R7）：点「删除」再点「取消」，记录仍在；点「确认删除」，记录消失。
- [ ] AC12（R7）：在 Web 上删除某条记录后，App 上保存修改或删除该记录，显示「找不到该记录」。
- [ ] AC13（R8）：编辑或确认删除某条记录时，其他记录的按钮禁用。
- [ ] AC14（R8）：后端不可达时搜索，显示可读的中文提示，App 不崩溃。
- [ ] AC15（打包）：`pnpm -F native check-types` 和 `pnpm -F native exec expo export --platform ios --output-dir dist` 通过。
