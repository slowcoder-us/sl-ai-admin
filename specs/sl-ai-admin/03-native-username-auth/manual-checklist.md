# 移动端用户名登录注册 - 模拟器手动验收清单

> 对应需求：[requirements.md](./requirements.md) 的 AC1–AC8（AC9 已由类型检查和 `expo export` 自动验证）
> 移动端没有自动化 UI 测试，以下步骤需要在 iOS 模拟器或 Android 模拟器里手动完成，结果记到交付报告。

## 准备

1. 数据库：`pg_isready -h localhost` 通过。
2. 启动后端：`pnpm dev:server`（:3000）。
3. 服务器地址：`apps/native/.env` 的 `EXPO_PUBLIC_SERVER_URL`
   - iOS 模拟器：`http://localhost:3000` 可直接用。
   - Android 模拟器：改成 `http://10.0.2.2:3000`（模拟器里的 localhost 是它自己），改完重启 Metro。
4. 启动 App：项目装了 `expo-dev-client`，首次需要构建开发版：`pnpm -F native ios`（或 `pnpm -F native android`）；之后用 `pnpm dev:native` 启动 Metro。
   - 本机是 Xcode 15.3，只有 iOS 17.4 模拟器运行时，可能达不到 Expo SDK 58 / RN 0.88 的要求。构建失败时，先升级 Xcode，或者改用 Android 模拟器。
5. 已存在的账号：可用共享测试账号 `test` / `test1234`（E2E 的 `global-setup` 会创建）；没有就先在 Web 或 App 里注册一个。
6. 起点状态：如果之前登录过，先点右上角「退出登录」，确认在登录页。

## 验收步骤

| AC | 步骤 | 预期结果 | 结果 |
|----|------|----------|------|
| AC1 | 未登录时冷启动 App | 启动时先短暂显示加载圈，不闪现首页，然后显示「登录」表单（用户名、密码、「登录」按钮、「没有账号？去注册」） | |
| AC1 | 点「没有账号？去注册」，再点「已有账号？去登录」 | 切到「注册」表单（用户名、密码、确认密码），再切回「登录」表单 | |
| AC2 | 在注册表单输入用户名 `ab`、密码 `1234567`、确认密码 `x`，点「注册」 | 三个输入框下方分别显示：「用户名格式不正确（3–20 位字母、数字或下划线）」「密码至少 8 位」「两次输入的密码不一致」；没有 toast，也不发请求（server 日志里没有 `/sign-up/email`） | |
| AC3 | 用一个新用户名（如 `Mobile_01`）和 8 位以上密码注册，两次密码一致 | toast「注册成功」，自动进入首页，显示「欢迎，Mobile_01」（大小写与输入一致），页面上没有邮箱 | |
| AC4 | 退出后，在注册表单用已存在用户名的不同大小写（如 `TEST` 或 `mobile_01`）注册 | toast「用户名已被注册」，仍停在注册表单 | |
| AC5 | 在登录表单用存在的用户名 + 错误密码登录 | toast「用户名或密码错误」 | |
| AC5 | 用不存在的用户名（如 `nobody_xyz`）登录 | toast 同样是「用户名或密码错误」 | |
| AC5 | 用正确的用户名和密码登录（用户名大小写随意） | toast「登录成功」，进入首页，显示「欢迎，<注册时的用户名>」 | |
| AC5 | 关掉后端（停止 `pnpm dev:server`），在登录页提交登录 | toast「登录失败，请稍后重试」；测完重新启动后端 | |
| AC6 | 未登录时打开深链接：iOS 运行 `xcrun simctl openurl booted sl-ai-admin://two`；Android 运行 `adb shell am start -a android.intent.action.VIEW -d sl-ai-admin://two` | App 仍停在登录页，看不到 Tabs 页面 | |
| AC6 | （补充）已登录时打开同一个深链接 | 进入 Tabs 的「two」页面，说明深链接本身可用 | |
| AC7 | 已登录时在首页点右上角「退出登录」 | 回到登录页 | |
| AC7 | 切到抽屉里的「Tabs」页面，点右上角「退出登录」 | 同样回到登录页（Tabs 页头也有退出入口） | |
| AC7 | 退出后从多任务界面杀掉 App 再打开 | 仍是登录页（SecureStore 中的会话已清除） | |
| AC7 | （补充）登录状态下杀掉 App 再打开 | 直接进入首页，不需要重新登录 | |
| AC8 | 在登录 / 注册表单提交时观察按钮（可在开发者菜单里开启网络限速，或关掉后端让请求变慢） | 提交过程中按钮禁用、显示加载圈，连续点击不会重复提交；请求结束后按钮恢复 | |
