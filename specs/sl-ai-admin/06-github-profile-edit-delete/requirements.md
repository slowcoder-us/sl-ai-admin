# GitHub 用户修改与删除（Web） - 需求

> 来源：`docs/首页需求.md` · 2.4 修改、2.5 删除、2.6 访问控制、4 交互要求
> 依赖：05-github-profile-save

## 背景

已保存的资料需要能维护：可以修改展示内容，也可以删除不再需要的记录。本 feature 提供修改、删除接口和列表上的就地操作。

## 用户故事

- 作为登录用户，我希望修改已保存记录的姓名、简介和所在地，以便内容符合我的需要。
- 作为登录用户，我希望删除前再确认一次，以便避免误删。

## 需求条目

| 编号 | 需求 | 优先级 |
|------|------|--------|
| R1 | 就地修改记录的姓名、简介、所在地，用户名和头像不可修改 | P0 |
| R2 | 修改内容有长度限制，三个字段都可以清空 | P0 |
| R3 | 取消修改时不保存 | P0 |
| R4 | 删除需要二次确认，取消时保留 | P0 |
| R5 | 只能修改和删除自己的记录，记录不存在时有提示，接口未登录返回 401 | P0 |
| R6 | 修改和删除过程防止重复提交，并限制同时只操作一条记录 | P1 |

### R1 修改

在列表中点「编辑」，该条记录就地变成表单，预填当前内容。点「保存修改」后更新数据库和列表，并退出编辑状态。

### R2 长度和清空

姓名最多 255 字，简介最多 500 字，所在地最多 255 字，首尾空格忽略。清空的字段保存为空，之后不再显示。

### R3 取消

点「取消」后退出编辑状态，数据不变。

### R4 删除确认

点「删除」后，该条记录显示「删除这条记录？」以及「确认删除」「取消」。点「确认删除」后删除并从列表移除；点「取消」则保留。

### R5 权限和记录不存在

`githubProfiles.update`、`githubProfiles.remove` 都需要登录，只能操作当前账号的记录。记录不存在或属于其他账号时，提示「找不到该记录」。

### R6 交互状态

修改、删除进行中相关按钮禁用。正在编辑或确认删除某条记录时，其他记录的「编辑」「删除」按钮禁用。错误显示在编辑表单或删除确认处。

## 验收标准

- [x] AC1（R1）：点「编辑」，表单预填当前的姓名、简介、所在地，没有用户名和头像的输入项。
- [x] AC2（R1）：修改三个字段并点「保存修改」，列表显示新内容，刷新页面后仍在。
- [x] AC3（R2）：提交长度超限的内容（简介 501 字），接口拒绝，数据不变。
- [x] AC4（R2）：清空三个字段并保存，列表不再显示这三项。
- [x] AC5（R3）：修改内容后点「取消」，列表内容不变。
- [x] AC6（R4）：点「删除」后再点「取消」，记录仍在。
- [x] AC7（R4）：点「删除」后再点「确认删除」，记录消失，刷新页面后也不存在。
- [x] AC8（R5）：账号 B 用账号 A 的记录 ID 调用 `update`、`remove`，返回 NOT_FOUND「找不到该记录」，数据不变。
- [x] AC9（R5）：未登录调用 `update`、`remove`，都返回 401。
- [x] AC10（R6）：编辑某条记录时，其他记录的「编辑」「删除」按钮禁用；确认删除时同样如此。
