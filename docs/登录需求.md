# 登录注册需求

## 1. 背景与目标

sl-ai-admin 管理后台需要最基本的账号体系：用户可以用 **用户名 + 密码** 注册、登录、退出（不需要邮箱），未登录用户不能访问后台页面。

覆盖端：Web（`apps/web`）、移动端（`apps/native`）。

## 2. 功能范围

### 2.1 注册

- 字段：
  - 用户名（必填，作为登录账号，全局唯一；3–20 位，只能包含字母、数字、下划线）
  - 密码（必填，至少 8 位）
  - 确认密码（必填，需与密码一致）
- 注册成功后自动登录，跳转到后台首页（`/dashboard`）。
- 失败提示：
  - 用户名格式不正确
  - 密码少于 8 位
  - 两次输入的密码不一致
  - 用户名已被注册

### 2.2 登录

- 字段：用户名、密码。
- 登录成功后跳转到 `/dashboard`。
- 失败统一提示「用户名或密码错误」，不区分是哪一项错误。
- 已登录用户访问登录页时，直接跳转到 `/dashboard`。

### 2.3 退出登录

- 在页面右上角的用户菜单中点「退出登录」，清除登录状态并回到登录页。

### 2.4 访问控制

- 未登录访问 `/dashboard` 等后台页面时，跳转到登录页。
- 需要登录的接口在未登录时返回 401（UNAUTHORIZED）。

## 3. 页面

| 页面 | 路径 | 说明 |
| --- | --- | --- |
| 登录 / 注册页 | `/login` | 默认显示登录表单，可切换到注册表单 |
| 后台首页 | `/dashboard` | 登录后可见，显示当前用户名 |

## 4. 交互要求

- 提交时按钮显示加载状态，防止重复提交。
- 表单校验错误显示在对应输入框下方；接口错误用 toast 提示。

## 5. 不在本期范围

- 忘记密码 / 重置密码
- 邮箱注册 / 邮箱验证
- 第三方登录（微信、GitHub 等）
- 手机号 / 验证码登录
- 记住我、多设备管理
- 角色与权限
